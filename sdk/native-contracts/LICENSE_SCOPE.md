The project owner confirmed the rights to publish the 28 selected sources under
Apache-2.0 and patent-disclosure clearance on 2026-10-28. The approval covers
source publication on `omelet-ai/optimization-context-protocol`, plus local
builds. See `provenance/PUBLICATION_APPROVAL.md` in the source repository.

The canonical source is Foundry commit
`7547036d1bc9464d6c43a9bdf7cff0a78e8560d7`. ORIGIN.json records the original and
packaged hashes. Python sources and OpenAPI are unchanged. TypeScript relocates
one package import and applies the versioned `cancel-uncertainty-1` text proposal:
a cancellation attempt does not prove termination. That proposal is not accepted
or installed in Foundry. Export barrels and package metadata are OCP packaging.
No existing Foundry checkout, worktree or Git metadata was changed.

Registry protection (`private` / `Private :: Do Not Upload`) remains because
npm/PyPI and release-asset publication were not requested. It does not restrict
the Apache-2.0 source grant. No private solver, credentials, operational data or
third-party dependency distributions are included in the source selection.
Dependencies retain their original licenses and notices.
