Recommended when invited

With an active invitation, the limited Omelet trial is the recommended first experience. Your inviter supplies a personal credential, exact HTTPS environment, supported profile, operating window and enforced quota. Use only synthetic data within the approved limits. Do not reuse expired sessions or request the internal engine token.

Read the invited trial instructions.

Core compliance never requires an Omelet account. This site sends no engine requests and accepts no keys.

Evaluate a TMS integration

Connect a delivery application to a checked routing example. Start with one depot, explicit distances and vehicle weight capacity; change an input and inspect the result before planning a larger integration.

Road travel times, delivery time windows and driver shifts need a separately agreed profile and implementation. The local example is not a production TMS or a commercial-engine benchmark.
