Start with local OR-Tools routing: discover supported rules, ask for missing inputs, solve, and explain independently checked results.

Install and connect

Download, verify and extract the native ZIP, then run these commands inside the kit with Python 3.12.

Check and connect the routing solver
python3.12 -B install.py
.native/bin/ocp-native doctor --domain routing-basic --evidence --probe
.native/bin/ocp-native config --domain routing-basic --evidence --name ocp-routing
.native/bin/python -I -B mcp_walkthrough.py --domain routing-basic --input routing-input.json

Expect a passing probe, eleven tools, one routing catalog and an independently checked 18-meter example. Copy the printed configuration into your local stdio MCP host.

Bring explicit distances

Supply one depot, mandatory visits, an integer meter distance matrix and kg vehicle capacities. Addresses, road travel times and time windows need a supporting profile and implementation.

The reference supports up to 64 visits and 16 vehicles. Other domains and BYO engines remain available through the same interface.

Keep the versions distinct

Python package 0.2.0a2; evidence feature 0.5.0; native contract 1; Core and routing profile 0.1.0.
