# 출처와 추적 범위

- [repository-selection](repository-selection.json): 사용자가 승인한 비공개 GitHub 저장소의 명시적 추적 파일 목록. 공개 allowlist가 아니다.
- [candidate-selection](candidate-selection.json): 독립 package 빌드·검토용 소스 선정 목록.
- [신규 개발 출처](DEVELOPMENT_SOURCES.md): 이 프로젝트에서 작성한 코드·문서와 검증 범위.
- [공개 정책](publication.json), [권리 검토](RIGHTS_REVIEW.md): 공개에 필요한 실제 결정. 현재 미완료.

원본 snapshot의 해시·원경로·미커밋 상태·이관 기록은 로컬 보유 공간에 보존하며 원격 저장소에서 제외한다. 원본 복사, 로컬 기술 검사, 비공개 Git 저장은 공개 라이선스·특허 허여·실제 고객 수락을 뜻하지 않는다.
