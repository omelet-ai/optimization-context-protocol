# 공개 권리 검토

상태: Pending. 새 폴더에 복사할 권한과 인터넷에 공개할 권한을 구분한다.

| 범위 | 상태 | 필요한 근거 |
| --- | --- | --- |
| 규격·schema·SDK·adapter·template | 미확정 | 저작권·기여 권리·제3자 의존성·선택 라이선스 |
| 특허와 API 설명 | 미확정 | 공개 파일·동작별 청구항 대조, 필요한 출원 접수·공개 결정 |
| 합성 사례·평가 자료 | 검토 전 | 출처·생성 방법·데이터 라이선스·실데이터 부재 |
| 내부 사업·특허·고객 채택 자료 | 공개 제외 | 필요한 내용만 별도 요약·승인 |
| 원본 snapshot | 공개 제외 | 재설계 후 명시 승인한 파일만 새 경로로 채택 |

실제 권리 상태나 유지보수 담당 실명을 추정하지 않는다. 공개 전에 LICENSE·NOTICE·기여 정책·지원 범위·독립 설치 증거와 publication allowlist를 확정한다.
