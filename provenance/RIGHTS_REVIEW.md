# 공개 권리 검토

상태: 2026-10-27 회사 담당자가 현재 선정 소스의 공개·Apache-2.0 배포 권한과 특허 관점 공개 가능 여부를 확인했다. [범위와 승인 기록](PUBLICATION_APPROVAL.md)을 따른다. 독립 법률 의견이나 특허 출원·등록 상태를 주장하지 않는다.

| 범위 | 상태 | 필요한 근거 |
| --- | --- | --- |
| 규격·schema·SDK·adapter·template | 담당자 공개·배포 권한 확인 | 선정 원본 소스 Apache-2.0, 제3자 의존성은 자체 조건 유지 |
| 특허와 API 설명 | 담당자 공개 가능 확인 | 법적 효력은 LICENSE에 따르며 특정 출원·등록 상태를 추정하지 않음 |
| 합성 사례 | 선정 파일 공개 확인 | 원격 선정 목록에 있는 합성 fixture만 포함, 실제 운영 데이터·실행 증거 제외 |
| 내부 사업·특허·고객 채택 자료 | 공개 제외 | 필요한 내용만 별도 요약·승인 |
| 원본 snapshot | 공개 제외 | 재설계 후 명시 승인한 파일만 새 경로로 채택 |

실제 권리 상태나 유지보수 담당 실명을 추정하지 않는다. 공개 전에 LICENSE·NOTICE·기여 정책·지원 범위·독립 설치 증거와 publication allowlist를 확정한다.
