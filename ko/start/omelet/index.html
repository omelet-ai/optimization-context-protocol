초대 시 권장

유효한 초대가 있다면 제한된 Omelet trial을 첫 체험으로 권장합니다. 초대자가 개인 인증정보·정확한 HTTPS 환경·지원 프로파일·운영 시간·서버에서 집행하는 한도를 제공합니다. 승인된 범위에서 합성 데이터만 사용하세요. 만료된 세션을 재사용하거나 내부 엔진 토큰을 요청하지 마세요.

초대받은 trial 사용 안내.

Core 적합성에는 Omelet 계정이 필요 없습니다. 이 사이트는 엔진 요청을 보내거나 키를 받지 않습니다.

TMS·배차 연동을 검토하세요

배송 앱을 검산 가능한 라우팅 예제에 연결하세요. 단일 출발지·명시 거리·차량 중량 용량으로 시작하고, 입력을 바꿔 결과를 확인한 뒤 더 큰 연동을 계획합니다.

실도로 이동시간·배송 시간창·기사 근무시간에는 별도로 합의한 프로파일과 구현이 필요합니다. 로컬 예제는 운영용 TMS나 상용 엔진 성능 벤치마크가 아닙니다.
