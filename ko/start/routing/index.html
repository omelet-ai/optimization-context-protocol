라우팅 프리뷰 v0.2.0-preview.2

유지보수 업데이트: 표준 상태·준비 상태 조회, 요청 추적이 가능한 입력 오류, 동시 작업과 장애 복구 검사를 추가했습니다. 기존 프로파일과 MCP 도구의 호환성을 유지합니다.

해당 GitHub 릴리스에서 native ZIP과 SHA256SUMS를 내려받으세요.

v0.2.0-preview.2 native ZIP과 SHA256SUMS

로컬 OR-Tools 라우팅으로 시작하세요. 지원 규칙을 조회하고, 빠진 입력을 질문하고, 문제를 풀어 독립 검산한 결과를 설명합니다.

설치와 연결

native ZIP을 내려받아 체크섬을 확인하고 압축을 푼 뒤, kit 안에서 Python 3.12로 다음 명령을 실행하세요.

라우팅 솔버 점검과 연결
python3.12 -B install.py
.native/bin/ocp-native doctor --domain routing-basic --evidence --probe
.native/bin/ocp-native config --domain routing-basic --evidence --name ocp-routing
.native/bin/python -I -B mcp_walkthrough.py --domain routing-basic --input routing-input.json

연결 점검 통과, 도구 11개, 라우팅 카탈로그 1개와 독립 검산한 18미터 예제를 확인하세요. 출력된 설정을 로컬 stdio MCP 호스트에 복사하세요.

명시적인 거리 데이터를 준비하세요

출발지 1곳, 필수 방문지, 정수 미터 거리 행렬과 kg 단위 차량 용량을 입력하세요. 주소, 도로 이동시간과 시간창은 이를 지원하는 프로파일과 구현이 필요합니다.

참조 구현은 방문지 최대 64곳과 차량 16대를 지원합니다. 같은 인터페이스로 다른 도메인과 자체 엔진도 사용할 수 있습니다.

버전을 구분하세요

Python 패키지 0.2.0a2, evidence 기능 0.5.0, native 계약 1, Core와 라우팅 프로파일 0.1.0입니다.
