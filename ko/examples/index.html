서로 다른 프로파일의 비용을 직접 비교할 수 없습니다. 저장된 합성 예제이며 브라우저 실시간 계산이나 운영 성능 벤치마크가 아닙니다. 현재 프로파일 한도 보기.

CSV에서 검산된 작업 배정까지

별도 CSV 데이터로 기준값·배정 비용 변경·가용 시간 변경을 비교합니다. 예상 합성 결과는 비용 12와 14, 그리고 비용값이 없는 증명된 불가능 시나리오입니다. 명령은 배정 표와 정확한 실행 기록을 저장합니다.

작업자 시나리오 분석을 로컬에서 실행
.agent/bin/python -I -B worker_analysis.py --workers worker-workers.csv --tasks worker-tasks.csv --costs worker-costs.csv --scenarios worker-scenarios.json --output worker-analysis-first --run-id worker-first

CSV 계약·분석 안내 보기. 로컬 명령이며 브라우저의 실시간 솔버 호출이 아닙니다.
