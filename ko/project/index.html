무엇이 공개되어 있나요?

Core 0.1·native v1 소스 후보·이 문서는 Apache-2.0으로 공개되어 있습니다. Native 소스에는 선정된 공통 계약과 이식 가능한 빌드 도구가 포함됩니다. 다음 native 프리릴리스 ZIP 을 사용하거나 native 빠른 시작으로 로컬 kit를 빌드하세요. 기존 Core import는 계속 지원합니다. 패키지 레지스트리와 공개 셀프서비스 trial 가입은 아직 열려 있지 않습니다.

왜 OCP인가?

앱 하나에는 솔버 API 직접 호출로 충분할 수 있습니다. OCP는 다른 앱·에이전트·호환 엔진이 추가될 때 공통 발견·요청·검증·결과·검산 인터페이스를 제공합니다. 임의의 엔진 교환이나 모든 산업의 지원을 보장하지 않습니다.

현재 검증 범위

현재 0.1.0 프로파일 계약
프로파일지원 문제와 한도이 프로파일의 미지원 항목
routing.basic방문 1–64개·차량 1–16대; 출발지 1개; 정수 미터 거리 행렬과 kg 용량.시간창·다회 운행·선택적 방문·소프트 제약.
worker.scheduling고정 시간 작업 1–8개·작업자 1–4명; 가용 시간·자격·중복·작업량·배정 비용.교대 근무표 생성·휴식·이동·초과근무·공정성 목적.
inventory.replenishment독립 상품 1–4개·일 단위 기간 1–6개; 주어진 수요·리드타임; 상품·기간당 주문량 ≤5; 용량 ≤50개.수요 예측·부족 재고·공유 창고나 예산·불확실한 수요.

이 한도는 현재 프로파일 계약에 속하며 OCP Core 전체의 범용 규모 한도가 아닙니다. 구현은 더 좁을 수 있습니다. 라우팅 교육용 엔진은 최대 방문 6개·차량 3대만 지원합니다. 요청을 만들기 전에 선택한 엔진의 지원 기능을 조회하세요.

Python/MCP/Node 설치와 예제를 자동 검사합니다. 범위가 한정된 기술 증거이며 외부 개발자의 도움 없는 수락, 운영 인증, 모든 모델·호스트와의 호환성을 뜻하지 않습니다.

라이선스·기여

자체 소스와 사이트 콘텐츠에는 Apache-2.0을 적용하며 타사 구성요소는 원래 라이선스를 유지합니다. 고지 문서: LICENSE, NOTICE 및 타사 라이선스 고지. 개선에 기여하기 또는 민감정보 없는 이슈 보고. 버전·운영체제·오류 코드를 포함하고 키나 고객 데이터는 게시하지 마세요.

보안 문제는 비공개로 보고하세요.

개인정보

이 정적 페이지에는 분석 도구·폼·타사 폰트·외부 스크립트·엔진 호출이 없습니다. 호스팅 제공자는 서비스 운영과 보안을 위해 IP 주소 등 요청 정보를 처리할 수 있습니다. 외부 문서 링크에는 해당 서비스의 개인정보 정책이 적용됩니다.

브라우저 예제

라우팅 그림은 빌드 시 실제 로컬 엔진으로 계산하고 독립 검산한 결과입니다. 실시간 솔버를 호출하지 않습니다. 로컬 실행 안내로 재현하세요.

소스 CI 통과가 기존 ZIP의 수정이나 재검증을 뜻하지 않습니다. ZIP에 동봉되거나 소스 커밋에 해당하는 문서를 따르고 버그 보고에 해당 버전을 명시하세요. Windows CI는 미지원 플랫폼 오류 안내만 확인합니다. Windows 설치·native Linux arm64·실제 외부 사용자의 도입은 미검증입니다.

TMS·배차 연동을 검토하세요

실도로 이동시간·배송 시간창·기사 근무시간에는 별도로 합의한 프로파일과 구현이 필요합니다. 로컬 예제는 운영용 TMS나 상용 엔진 성능 벤치마크가 아닙니다.
