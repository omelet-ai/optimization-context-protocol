# Security reporting for the developer preview

The current candidate is not a production service and has no supported public
release series or security response SLA.

If you received an evaluation invitation, privately contact your inviter through
the original channel. Include the candidate artifact SHA-256, affected component,
synthetic reproduction, and impact. Do not include trial keys, internal service
tokens, customer data, or a publicly accessible exploit in an issue or pull request.

For private vulnerability reports use GitHub's
[Report a vulnerability](https://github.com/omelet-ai/optimization-context-protocol/security/advisories/new)
for this repository. Do not post vulnerabilities or secrets in public issues.
If the reporting form is unavailable, use the existing private invitation
channel and wait for a private route; do not invent an email address or expose
the report publicly. No response-time commitment is promised.
