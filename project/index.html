OCP is an Apache-2.0 open-source developer preview. Start from the public source: no account, trial key or model call is required. Package registries and hosted trial enrollment are not open.

View source on GitHub ↗

Why use OCP?

A direct solver API can be enough for one app. OCP adds a shared discovery, request, validation, result and checking boundary when another app, agent or compatible engine enters the picture. It does not promise arbitrary-engine interchangeability or universal industry coverage.

Python/MCP/Node installation and examples are exercised automatically. This is bounded technical evidence, not unaided external developer acceptance, production certification or compatibility with every model/host.

License and contribution

Original source and site content use Apache-2.0; third-party components retain their licenses. Read LICENSE, NOTICE and third-party notices. Contribute improvements or report a non-sensitive issue. Include version, operating system and an error code; never post keys or customer data.

Privacy

These static pages contain no analytics, forms, third-party fonts, external scripts or embedded engine calls. The hosting provider may process request information, including IP addresses, for service operation and security. External documentation links use their own privacy policies.
